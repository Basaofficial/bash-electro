# bash-electro

Planer elektro instalacija i ormara (Verteiler) za njemačko tržište: 3D kuća, 3D Verteiler, montaža, strujni krugovi, proračun (Ib, Iz, ΔU, Abschaltbedingung), Prüfprotokoll i PDF dokumentacija.

**Pokreni u pregledniku:** https://basaofficial.github.io/bash-electro/

Na telefonu otvori link i izaberi *Dodaj na početni ekran* / *Instaliraj aplikaciju*. Android APK je u [Releases](../../releases).
